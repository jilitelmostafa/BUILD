5. Intégration Web & HTML (Web Mapping / SIG)

Q9. Structure de base et intégration d'une carte

Vous souhaitez intégrer une carte interactive (venant d'un serveur cartographique) dans une page web à l'aide d'une balise qui permet d'insérer une autre page HTML. Quelle balise devez-vous utiliser ?

Réponse correcte : B
La balise <iframe> (Inline Frame) est la balise standard utilisée en intégration web et en Web SIG pour intégrer un contenu externe (comme une carte interactive Google Maps, ArcGIS ou Leaflet) directement dans une page HTML. La balise <map> sert uniquement à définir une image cliquable.

Q10. Syntaxe des liens et chemins

Pour créer un bouton ou un lien texte dans une pop-up SIG permettant de télécharger un rapport PDF situé dans le même dossier que votre page web, quelle est la syntaxe HTML correcte ?

Réponse correcte : B
En HTML, la balise de lien est <a> (ancre) et l'attribut utilisé pour spécifier la cible ou l'adresse du fichier est obligatoirement href (Hypertext Reference). La balise <link> sert à lier des ressources externes comme des feuilles de style CSS dans le <head>.

Q11. Affichage d'images et texte alternatif

Lors de la configuration d'un tableau de bord (Dashboard) pour la SRM, vous insérez un logo ou un schéma technique à l'aide d'une balise image. Quel attribut devez-vous obligatoirement ajouter pour assurer l'accessibilité (si l'image ne charge pas) ?

Réponse correcte : B
L'attribut src indique le chemin de l'image (obligatoire pour l'affichage), mais c'est l'attribut alt (alternative text) qui est obligatoire pour l'accessibilité. Il permet d'afficher un texte de remplacement si l'image est introuvable ou lue par un outil pour malvoyants.
